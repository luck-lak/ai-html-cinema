# AI 单页动画

这是我无聊的时候让AI做的，用单HTML文件展示带有剧情的动画，感觉这是一个很有意思的娱乐，以后AI越来越强时，也许会生成更多有意思，震撼的动画

现在看着其实都有点拉，应该和我提示词太随意有关系，所以其实和我想要的有点差距，但是也有点新意

不知道为什么，感觉这些生成的都有相同的风格，以后看一下能不能有一些更有新意的东西，从内容到风格

## 在线放映

[进入一页影院](https://luck-lak.github.io/ai-html-cinema/)

首页提供作品导航，可按 Chatgpt / Gemini 筛选，点击封面直接观看。

## 作品

### Chatgpt

由 Codex + GPT-6 Astra 生成。

- [流浪地球·越过木星](Chatgpt/流浪地球-越过木星.html)
- [侏罗纪公园·雨夜失控](Chatgpt/侏罗纪公园-雨夜失控.html)

### Gemini

由 Gemini Spark 生成。

- [战舰·午夜风暴](Gemini/战舰-午夜风暴.html)
- [流浪地球·木星危机](Gemini/流浪地球-木星危机.html)

## 观看方式

下载 HTML 文件后，用支持 WebGL 的现代浏览器打开，点击页面中的播放按钮即可观看。

Gemini 作品通过 CDN 加载 Three.js 等脚本，需要联网；Chatgpt 作品已内嵌 Three.js。每个作品均保留生成时的原始 HTML 内容。
